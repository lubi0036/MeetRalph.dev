# MeetRalph.dev

MeetRalph.dev is Ralph Lubin's peaceful, cosmic developer portfolio. It is a responsive static website that presents skills, selected projects, an about section, and a contact form.

## Features

- Cosmic animated star background
- Light and peace display modes
- Responsive desktop and mobile layout
- Front-end, back-end, and database skill categories
- Interactive project previews with technology details and GitHub links
- Accessible navigation and contact form validation

## Technologies

- HTML5
- CSS3
- JavaScript
- C#
- ASP.NET / MVC
- Laravel / PHP
- MySQL
- SQLite
- PostgreSQL

## Run Locally

Open `index.html` directly in a browser, or use a local static server:

```powershell
python -m http.server 5500
```

Then visit `http://localhost:5500`.
